# Weatherly

A lightweight weather and local-time dashboard, designed to run as a static site on GitHub Pages. It uses the free, no-key [Open-Meteo](https://open-meteo.com/) weather and geocoding APIs.

## Run locally

Open `index.html` in a browser, or serve this folder with any static-file server.

## Publish to GitHub Pages

1. Create a GitHub repository and upload these files.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

GitHub will provide the live site URL shortly afterward.
